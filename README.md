# Somos Trama - Agencia de Marketing 🚀

Este proyecto es el sitio web oficial desarrollado para la agencia de marketing "Somos Trama". Funciona como una carta de presentación digital diseñada para captar potenciales clientes, generar confianza y mostrar el alcance de la empresa.

## 📌 Características Principales

*   **Servicios:** Un catálogo claro y detallado de las soluciones y servicios profesionales que ofrece la agencia.
*   **Nuestro Equipo:** Una sección dedicada a presentar a las personas que conforman el equipo de trabajo, humanizando la marca.
*   **Alcance Geográfico:** Información específica sobre las ciudades y zonas donde la agencia tiene cobertura operativa.
*   **Diseño Intuitivo:** Interfaz pensada para que el usuario encuentre la información de contacto y los servicios de forma rápida.
